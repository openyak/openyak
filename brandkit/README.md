## 品牌核心

- 名称：**OpenYak**，注意大小写。Logo 图形内部是 **YAK**，不是另一个产品名。
- 口号：**One chat. Every agent.** 保留标点和大小写，不擅自添加能力保证。
- 气质：直接、有活力、清晰，带一点贴纸式的个性。不是霓虹科幻或传统企业科技风。
- 识别点：倾斜的粗字形、厚黑边、白色外轮廓；Y 奶油黄、A 白、K 蓝绿色。

## 配色

以下黄、蓝值复用 App 现有 `--brand-yellow` / 浅色 `--accent` token；它们是后续设计的统一目标色，不代表生成图片的每个像素都精确相同。

| 颜色 | HEX | 使用方式 |
| --- | --- | --- |
| 奶油黄 | `#FFEDA3` | Y、重点短句、小面积强调 |
| 品牌蓝绿 | `#0177AA` | K、少量边角图形；不要替换成电光皇家蓝 |
| 白 | `#FFFFFF` | A、外描边、主标题 |
| 黑 | `#000000` | Banner 主背景、Logo 内描边 |
| 炭灰 | `#212121` | 很弱的轮廓装饰；不得与主内容争抢注意力 |

## 字体与排版

- **Logo 只能使用素材，不能靠输入“YAK”再找近似字体重造。** 禁止拉伸、重排字母、改变描边或单独调色。
- 当前 Banner 的 OpenYak 标题是生成图中的粗体斜体字形，没有可验证的字体名称或独立字体文件。不要把某个商业字体写成“官方字体”。
- 新的可编辑排版使用粗体、略向前倾的无衬线方向；正文保持清晰的系统无衬线。需要品牌字标精确一致时，复用现有批准素材。
- 保持两层信息：标识/名称为主，口号为次。不堆叠产品特性、按钮或运行时 Logo。
- README Banner 使用 3:1 宽幅。Logo 在左、名称与口号在右，垂直重心平衡，主内容不裁切。
- 主内容与画布边缘建议保留至少画布高度的 10%；围绕 Logo 留白至少相当于 A 字高度的 15%。缩到 900px 宽时仍应清晰可读。

## 图形风格

可以使用：黑色平面背景、少量斜切黄/蓝色块、与 Logo 角度相关的低对比度轮廓。装饰放在边角，中心内容区保持干净。

不要使用：网络连线与发光节点、随机科技图标、机器人/动物吉祥物、紫蓝霓虹渐变、金属或 3D 浮雕、镜头光晕，以及假装成产品截图的生成界面。

这套规则用于**品牌宣传素材**。不要把粗斜体 Logo 风格或白色粗描边套到聊天正文、权限卡片或整个产品 GUI。

## 复用与维护

1. 首先读本文件；确认要制作的是品牌素材还是产品截图。
2. 品牌设计必须附带 `logos/app-icon-1024.png` 作为参考，保留 Logo 的视觉身份。
3. 生成工具可能改变字形。当前 Banner 是品牌参考下的生成适配，不是像素级粘贴；需要精确商标图形时，使用原 Logo 在可编辑设计源中排版，不从 Banner 反向提取新 Logo。
4. 新候选素材先使用新文件名，确认后再替换正式版本；记录参考、工具、提示词、实际尺寸，不把候选图称为已发布版本。
5. App 运行时目前仍从 [`app/src/main/assets/`](../app/src/main/assets/README.md) 打包素材，避免跨目录资源构建风险。这里的 Logo 是相同原文件的品牌参考副本；更新原 Logo 时需显式同步两处并运行图标测试。
6. 历史 GIF/视频不得作为“最新版”截图使用；演示数据要明确标注，不能包含私人聊天或账号信息。
